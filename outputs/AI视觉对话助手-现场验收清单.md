## 视觉理解 2/3 验收

使用前端对话区的 3 个快捷问题，每题记录是否基于实时画面回答正确。

| 问题 | 预期观察 | AI 回答摘要 | 是否正确 |
| --- | --- | --- | --- |
| 画面里有什么？ |  |  |  |
| 主要颜色是什么？ |  |  |  |
| 我手里拿着什么？ |  |  |  |

结论：`通过` / `未通过`

通过标准：3 题至少答对 2 题。
